## 最终方案与复现

- **任务**是用 EEG 给 200 个未见图像类别排序。正确类别排第一计入 Top-1，排在前五计入 Top-5。
- **模型**接收 17 通道、100 Hz 数据中刺激后的 80 个采样点。EEG 经过 5、11、21 点多尺度时间卷积、电极门控、空间卷积和四点平均池化，再用残差投影和 L2 归一化得到 768 维向量。模型有 889,353 个可训练参数，图像特征和候选模板沿用冻结的 CLIP。[编码器代码](../../eeg_model.py) · [结构图](figures/current_eeg_model.png)
- **训练**时，每轮为每张图等概率抽 2、3 或 4 条原始试次，无放回取样后平均。每组使用 1,654 个官方训练类的 16,540 张图，Adam 学习率 `0.0002`、批大小 `128`、固定 `100` 轮。损失是 `0.75 × 双向 InfoNCE + 0.25 × 余弦回归 + 0.10 × Top-5 排序损失`，温度固定 `0.07`。每条 EEG 的排序项使用 1 个正确类与 199 个错误类。正确类模板排除当前配对图像，第 5 高的错误类分数超过正确类时才产生惩罚。[训练代码](../../eeg_train.py) · [正式协议](round-15/full/protocol.json)
- **评分**时，先计算 EEG 向量和冻结模板的余弦分数，再用该被试的 16,540 条标准四次平均训练 EEG 建校正库，应用 QB-Norm `β=20, k=1`。QB-Norm 调整评分，不更新网络权重。每组正式查询是 200 类对应的标准 80 次平均 EEG。训练曾中断并从断点恢复，所有 50 组训练完成后统一评分。[评分代码](../../eeg_querybank.py) · [复现实验入口](../../eeg_top5_qb_pilot.py)

50 组训练记录合计约 3 小时，峰值分配显存约 741 MiB。运行环境和公开数据准备方式见[运行说明](../../README_EXPERIMENT.md)。

```powershell
python -m unittest discover -s tests
python eeg_top5_qb_pilot.py --full
```

## 15 轮开发实验

2026、2027、2028 是划分开发验证类别时使用的随机种子。每个划分从官方训练类中留出 200 类，使用 1,000 条验证查询。2027 和 2028 的验证类与此前划分的验证类不重叠。训练种子 `0–4` 用于正式评测的重复训练。

| 轮次 | 改动 | 开发集 Top-1 / Top-5 | 观察 |
|---|---|---:|---|
| 1 | 四点池化下换成单尺度卷积 | 7.350% / 22.775% | Top-1 降 0.425 个百分点，Top-5 基本持平。[数据](round-01/summary.json) |
| 2 | 池化前加残差 `1×1` 特征混合 | 7.425% / 22.625% | 两项都略降。[数据](round-02/summary.json) |
| 3 | 加残差非线性投影头 | 7.375% / 24.850% | 四人 Top-5 均提高，均值增加 2.150 个百分点，Top-1 下滑。[数据](round-03/summary.json) |
| 4 | 学习 InfoNCE 温度 | 6.550% / 20.500% | 四组温度均触及 0.01 下限，两项明显下降。[数据](round-04/summary.json) |
| 5 | 固定温度，加余弦回归 | 7.775% / 24.450% | 四人 Top-1 均较第 3 轮恢复。后续加 CSLS 通过独立复验。[数据](round-05/summary.json) · [复验](round-05/csls_replication/summary.json) |
| 6 | 在线 `2–4` 次试次子集平均 | 9.075% / 26.800% | 通过先导和独立复验，正式评测也获益。[数据](round-06/pilot/summary.json) · [复验](round-06/replication/summary.json) |
| 7 | CLIP 批内软目标 | 8.825% / 26.875% | Top-5 微涨，Top-1 下滑。[数据](round-07/pilot/summary.json) |
| 8 | 跨被试预训练后微调 | 8.650% / 27.792%（复验） | 一个预训练种子的先导过线，2027 独立复验两项均落后。[复验](round-08/replication/summary.json) |
| 9 | 两模型的 CSLS 分数融合 | 10.575% / 30.192% | CNN 与跨被试模型融合提高 Top-5 2.408 个百分点，作为开发探索记录。[数据](round-09/development/summary.json) |
| 10 | 原始波形上的电极残差自注意力 | 9.200% / 26.150% | Top-5 下降 0.650 个百分点。[数据](round-10/pilot/summary.json) |
| 11 | 单试次、输入扰动和权重 EMA | 9.325% / 27.525% | 完整方案的 Top-5 提升 0.725 个百分点，未过门槛。[数据](round-11/pilot/summary.json) |
| 12 | 展平时空输入的 EEGProject MLP | 6.475% / 20.925% | 纯 MLP 明显退步，和 CNN 做分数融合也未提高 Top-5。[数据](round-12/pilot/summary.json) |
| 13 | 固定权重，将 CSLS 换成 QB-Norm | 9.150% / 27.175% | 先导小涨，正式补评的 Top-5 提升 1.72 个百分点。[数据](round-13/pilot/summary.json) |
| 14 | EMA 方案的高斯噪声 `0.10→0.05` | 9.750% / 27.875% | 相对原噪声，4,000 条查询净增 1 次前五命中。[数据](round-14/pilot/summary.json) |
| 15 | Top-5 排序辅助损失 | 9.525% / 27.325% | 先导未过原门槛。按要求锁定配置跑全量，正式两项超过课程参考线。[数据](round-15/pilot/summary.json) |

更早的[视觉近邻负样本](../visual_negatives/summary.json)、[类别原型对齐](../class_alignment/summary.json)、[嵌入居中](../embedding_center/summary.json)、[加权池化](../weighted_pool/summary.json)、[岭回归融合](../ridge_fusion/summary.json)和[试次分数后平均](../late_average/summary.json)都停在开发阶段。四点池化相对等参数的 `ab_pool8_stride4` 在开发复验只提高 0.038 / 0.450 个百分点，池化时间分辨率与投影容量各自的贡献仍需区分。[等参数复验](../pooling_replication/summary.json)
