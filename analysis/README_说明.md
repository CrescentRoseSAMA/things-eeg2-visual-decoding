## 五、方法与边界

- 主音轨用**录屏音轨**（单声道），因为同段比较中它明显优于独立录音（后者漏词、专名错乱）；独立录音只用于疑点复核。
- 转录未做逐字对齐：`segment` 的起止是**分段边界**，不是句子时间；引用时按"片段区间"处理。
- 52 页课件按每批 ≤8 页分 7 批提取，主分析者复核全部作业相关页、每批抽检 ≥1 页。
- **未人工听校**（分析者不能直接听辨）。可靠性来自：另一路音轨同段复核、疑点短块重转、课件逐页比对。
- 3 处转录异常（4 分钟静音、1 处循环、8 段术语表回显）已补转核查；补转文本在报告中标注来源。
- 录屏为幻灯片共享画面，不含教师本人画面，无法核对板书或现场演示细节。
